# Cloud Computing Concepts Reflection

Cloud computing has changed the way I study, communicate, and access information every day. The cloud services that I frequently use are YouTube, Google Drive, and Zoom. These applications allow me to watch educational videos, store important school files, and attend online meetings from different devices with an internet connection.

YouTube is classified as *Software as a Service (SaaS)* because users can stream videos online without managing the software or servers that run the platform. It uses the *Public Cloud* deployment model because it is available to anyone with internet access and is hosted on Google's cloud infrastructure.

Google Drive is also an example of *Software as a Service (SaaS)* because it provides online file storage and sharing services. Users can upload, organize, and access their documents from anywhere without maintaining physical storage devices. It is considered a *Public Cloud* service since it is available to all Google account holders.

Zoom is another *Software as a Service (SaaS)* application because it provides online video conferencing through the internet. It also uses the *Public Cloud* deployment model because users can join meetings from different locations while Zoom manages the cloud infrastructure behind the service.

Version control is an essential part of cloud computing because it keeps a complete history of changes made to files and projects. Git and GitHub help developers collaborate efficiently by allowing multiple people to work on the same project without overwriting each other's work. Features such as commits, branches, and pull requests make it easier to review updates, resolve conflicts, and restore previous versions if needed. These tools improve teamwork, reduce errors, and ensure that cloud-based projects are managed in an organized and reliable way.
